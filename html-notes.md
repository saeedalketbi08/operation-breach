# HTML Notes

## The shape of every element
open tag + content + close tag

## Heading
```html
<h1>Operation Breach</h1>
```
What it does: Writes a heading called operation breach

## Link
```html
<a href="https://tryhackme.com">TryHackMe</a>
```
What it does: creates a link to tryhackme
What `href` means: used to specify the url

## Button
```html
<button>Start</button>
```
What it does: creates a button you can press for example for a login

## Tag vs attribute
the tag decides what the element is, and attribute adds the settings or info

## ID
An id gives an element a unique name, so CSS, JavaScript or a link can find that exact element.
