# Linux Cheat Sheet

- **SSH**: lets you connect and control another computer remotely by typing commands. Example: `ssh bandit0@bandit.labs.overthewire.org -p 2220`
- **ls**: shows you the files in the folder youre in right now. example typing the command `ls` will show you the files in the folder 
- **file**: tells you what type of file. Example: typing `file readme` will show you the type of file it is
- **cat**: prints whatever is in the file. example: typing `cat readme` will show you whats in the file
- **exit**: it logs you out of the server. typing `exit` will make you log out of the page or window.
- **./**: . means the folder youre at right now, / means inside the folder, youll need it when theres a dash (-). Example: `cat ./-`, the - is the file name without the ./ the linux will think the dash is an option.
- **" "**: means that theres a name that has spaces using the quote will make the linux know that its the file name. Example `cat ./"--space in the filename--"`
- **find**: searches for files that match their label size or owner. example: `find . -size 1033c`
- **du -b**: shows how much space the files takes up in bytes. example: `du -b`
- **-size**: an option that tells find to match the files by their size. example: `find . -size 1033c`
- **cd**: lets you go into a directory. example `cd inhere`
- **-a**: shows all files including hidden files. example: `ls -a`
- **`*`**: shows every file name. example: `file ./*`
- **..**: lets you get back to the previous folder. example `cd ..`
- **`/`**: its the top folder of the whole server. example: `find /`
- **-user**: it tells the find to match files owned by a specific username. example: `find / -user bandit7`
- **-group**: tells the find to match the files owned by a specific group name. example: `find / -group bandit6`
- **2>/dev/null**: removes the errors and throws them in the trash and then shows you the correct ones. example: `find / -user bandit7 -group bandit6 -size 33c 2>/dev/null `
- **grep**: finds lines inside a file. example: `grep millionth data.txt`
- **sort**: sorts the lines in alphabetical order. example `sort data.txt`
- **uniq**: looks at lines that are under each other and deals with the ones that apear more than once, -u shows lines that appear once only. example `sort data.txt | uniq -u`
- **|**: The pipe takes the result of the first command then hands it to the second one. example: `ls | sort`
- **--help**: shows a commands options and what each one does, its like a built in instruction manual. example: `uniq --help`
- **strings**: goes through a binary file and shows you the text that are readable only. example: `strings data.txt`
- **base64**: encodes data rewriting the data with random letter and numbers and ends with = at the end. -d decodes the data. example: `base64 -d`
- **tr**: changes characters for other characters. example: `cat data.txt | tr 'A-Za-z' 'N-ZA-Mn-za-m'`
- **ctrl+c**: cancels whatever is running. example: `ctrl+c`
- pwd : shows which folder im in currently. Example: `pwd`
- mktemp -d: creates you a new folder, in /tmp, with a random hard-to-guess name, and it prints that name. Example: `mktemp -d`
- ~ : your home folder. example: cp `~`/data.txt .
- . : current folder. example: cp ~/data.txt `.`
- cp ~/data.txt . :copies the file data.txt from your home folder to the current folder. example: `cp ~/data.txt .`
- `>` : takes result and places it in a file instead on the screen ( can overwrite without warning). `example: xxd -r data.txt `>` data1`
- xxd -r : reverts a hexdump into the original file. example: `xxd -r data.txt > data1`
- gzip -d : decompresses the gzip file. example: `gzip -d data1.gz`
- bzip2 -d : decompresses the bzip2 file. example: `bzip2 -d data6.bz2`
- tar -xf : extracts files from a tar archive. example: `tar -xf data1.tar`
- mv : renames the file moves files ( can overwrite without warning). Example: `mv data1 data1.gz`
