# Acronyms

| Acronym | Stands for | What it means | OSI layer / port |
|---|---|---|---|
| IP| Internet Protocol| It's a digital address for computing devices allowing them to send and receive data across internet and any network| Layer 3 |
| MAC |Media access control| Its the address placed by the manufacturer to be able to identify devices| Layer 2|
| LAN| Local area network| Devices connected to a small area| Layer 1-2|
| OSI|Open systems interconnection| a model that has 7 layers to show data travels from one computer to another | ALL LAYERS|
| TCP| Transmission control protocol |communication standard that is reliable| Layer 4|
| UDP| User datagram protocol| the data is received as quickly as possible, however it does not check that the data arrived| Layer 4|
| HTTPS| Hypertext transfer protocol secure| Encrypts data between browser and web, securing it| Layer 6/443|
| RAM| Random access memory| Temporary memory when computer is turned off the memory is gone so basically short term memory but fast | N/A hardware|
